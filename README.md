# Game of Thrones Death Timeline (Gantt Chart in R)

This repository visualizes the episode-level death arcs of over 45 characters from *Game of Thrones* using `ggplot2` in R.

### 📊 Features:
- Gantt-style bars showing first to last appearance
- Screen time–based color scale
- Labels with character name and death style

### 📁 File
- `got_gantt_chart.R` — full R script

---

### 📦 Dependencies
- `ggplot2`
- `viridis`

Run `install.packages(c("ggplot2", "viridis"))` to install.
